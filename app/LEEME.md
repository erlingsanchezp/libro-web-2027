# SEO GEO y Tracking para construir sitios web en 2027

Guía práctica de cero a nivel avanzado.

## Cómo comenzar

1. Extrae todo el ZIP en una carpeta de tu computadora.
2. Abre Libro_SEO_GEO_Tracking_Web_2027.pdf para leer. El índice y las referencias tienen enlaces.
3. Conserva el archivo DOCX si quieres añadir notas o adaptar el contenido. Su paginación puede cambiar según el editor; el PDF conserva la edición maquetada.
4. Sigue el plan de doce semanas del anexo 5 y compara tus entregas con las soluciones de los laboratorios y el proyecto resuelto.

## Recursos de práctica

La carpeta recursos contiene cinco plantillas editables en texto, datos simulados en JSON, soluciones numéricas y una página de práctica.

Para usar el simulador, abre recursos/practica/index.html en un navegador actualizado con JavaScript habilitado. No necesitas instalar programas ni conectarte a Internet. Comienza con el registro desactivado; permite luego los eventos de práctica y prueba el error de formulario, la aceptación y los reintentos. Cada recarga reinicia el registro.

El simulador es un entorno didáctico local. No envía información ni confirma solicitudes, compras o citas reales. El libro explica qué servicios y comprobaciones necesitaría una implementación de producción.

Consulta recursos/LEEME.md para relacionar los archivos con los ejercicios. Las plantillas .md se pueden abrir en un editor de texto; duplica cada una antes de completarla. El archivo JSON se puede leer como texto o importar en una herramienta compatible.

## Contenido de la edición

87 páginas, 32 capítulos, nueve laboratorios con soluciones, seis anexos, un proyecto final y 57 referencias principales. Los casos públicos incluyen Rakuten 24, Google Merchandise Store y GOV UK. Insalud se utiliza como propuesta didáctica de integración, sin atribuirle resultados ni una auditoría de su sitio actual. Las cifras de ejercicios están identificadas como simuladas.

También se incluye el manuscrito en Markdown y sus figuras en assets. Mantén esa carpeta junto al archivo .md para que las imágenes se vean en un lector compatible.
